Sei alla prima esperienza? Apri la guida per iniziare

Non devi sapere programmare. Questo spazio collega le schede dei laboratori immagini, voce e video. I materiali originali vanno conservati a parte.

Facciamo un esempio: prepara «Il viaggio di una goccia d'acqua» per una prima media. Prima usa una figura per osservare il ciclo, poi una breve narrazione per capire le fasi, infine un video per vedere la sequenza. Gli studenti ricostruiscono e spiegano il processo.

Che cos'è una scheda JSON? Un file scaricato dallo Studio che registra obiettivo, provenienza e verifica, ma non contiene la fotografia, la voce o il video.

Esempio fittizio, sempre modificabile e mai approvato automaticamente
Privacy e file · tutto rimane sul tuo dispositivo

Gli Studi precedenti esportano schede JSON senza file multimediali. Qui importi quelle schede e verifichi le dichiarazioni di approvazione. I media originali vanno conservati e consegnati separatamente. Nessun file viene trasmesso a un server.

Che cosa deve fare il docente?

04 / Gate docente

Consegna solo dopo la verifica

Che cosa deve fare il docente?

Apri gli originali, verifica le fonti, ascolta l'audio e guarda il video. Spunta i controlli soltanto se li hai davvero eseguiti.

L'assemblaggio di tre lavori non implica automaticamente la correttezza del prodotto finale.

05 / Consegna professionale

Esporta il progetto

Che cosa deve fare il docente?

Il file JSON conserva i dati modificabili; la scheda HTML è leggibile offline. Consegna i media originali separatamente.
