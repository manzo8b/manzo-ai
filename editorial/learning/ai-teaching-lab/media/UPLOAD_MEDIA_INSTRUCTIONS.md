# AI Teaching Lab — Materiali della presentazione del corso

Questa directory raccoglie i materiali audiovisivi e la documentazione per il corso **Intelligenza artificiale e didattica applicata**.

## Materiali da caricare

| File | Formato | Dimensione indicativa | Utilizzo |
|---|---|---:|---|
| `AI_per_Docenti.web.mp4` | H.264/AAC, 960×540 | 5,8 MB | Video podcast di apertura, durata 07:04 |
| `IA_e_Progettazione_Didattica.pdf` | PDF (15 slide illustrate) | 17,3 MB | Download della presentazione originale |
| `IA_e_Progettazione_Didattica.pptx` | PowerPoint (15 slide prevalentemente immagine) | 18,8 MB | Download del formato PowerPoint originale |

**Stato:** questi binari non sono inclusi nei commit testuali finché non vengono caricati. La pipeline di GitHub Pages rileva automaticamente **soltanto i file realmente presenti** e abilita il video player e i collegamenti PDF/PPTX. In assenza dei file, la landing mostra una spiegazione editoriale invece di link non validi.

### Caricamento

1. Aprire la cartella [media su GitHub](https://github.com/manzo8b/manzo-ai/tree/main/editorial/learning/ai-teaching-lab/media) dopo l'unione della PR.
2. Selezionare **Add file → Upload files**.
3. Selezionare i tre file dalla cartella `media/` del pacchetto consegnato in chat, **non il file ZIP**.
4. Confermare nel branch principale `main`.
5. La pipeline `Deploy MANZO AI` ricostruirà e pubblicherà le risorse nella directory pubblica `/it/formazione/ia-per-la-didattica/media/`.

L'interfaccia web GitHub limita i file caricabili, quindi il video è stato ottimizzato sotto i 25 MB. Non modificare i nomi senza aggiornare `theme/publish-ai-teaching-lab.py`.

### Accessibilità e precisione

La pagina [presentazione del corso](https://manzo8b.github.io/manzo-ai/it/formazione/ia-per-la-didattica/presentazione/) contiene una **trasposizione testuale** delle 15 slide che rende i messaggi consultabili senza leggere immagini. **Non** è una copia grafica dei file originali. I sottotitoli verificati del video non sono ancora disponibili.

Il riferimento a John Dewey della slide 12 è trattato come **parafrasi interpretativa**, non citazione testuale autentica. Le esercitazioni in pagina elaborano le risposte localmente, ma non è corretto affermare che qualsiasi servizio usato dai docenti sia automaticamente conforme al GDPR.

Il materiale è di tipo divulgativo, non accreditato e senza attestazioni automatiche.
